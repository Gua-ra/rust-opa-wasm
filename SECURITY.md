# Security policy

This repository is Gua's fork of [matrix-org/rust-opa-wasm](https://github.com/matrix-org/rust-opa-wasm) with no code changes. [gua-auth-service](https://github.com/Gua-ra/gua-auth-service) pins upstream commit `a3b8cb70` from it.

## Report a vulnerability

A vulnerability in the crate belongs upstream, under the [Matrix.org security disclosure policy](https://matrix.org/security-disclosure-policy/).

For something specific to this fork or to the commit gua-auth-service pins, report it privately to Gua. If this repository's Security tab shows **Report a vulnerability**, use it. Otherwise, email [support@gua.global](mailto:support@gua.global) with "Security" in the subject. The mailbox is not encrypted, so keep the first message to a short description.

Do not open a public issue for a security problem.
